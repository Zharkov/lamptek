# LampTek — сайт на Flask

Сайт светодиодного освещения: каталог с админкой (CRUD товаров) и корзина-заявка
без оплаты — при отправке менеджеру летит уведомление (email + опционально Telegram).

## Стек
- **Flask** + **Flask-SQLAlchemy** + **Flask-Login** + **Werkzeug** + Jinja2
- **SQLite** (`instance/lamptek.db`) — создаётся и наполняется автоматически при первом запуске
- HTML / CSS / ванильный JS (тема, корзина, ползунок температуры, лайтбокс)

## Быстрый старт
```bash
pip install -r requirements.txt
cp .env.example .env                 # по желанию; локально можно не трогать
python scripts/fetch_assets.py       # один раз: качает реальные фото со старого сайта (нужен интернет)
python app.py                        # http://localhost:5000
```
- Сайт: http://localhost:5000
- Админка: http://localhost:5000/admin/login — логин/пароль из `.env` (по умолчанию `admin` / `Admin2024!`)
- БД и тестовые данные (7 товаров, демо-заявка, админ) создаются сами при первом запуске.
- Без `fetch_assets.py` сайт работает с картинками-заглушками.

## Что внутри
- Главная: герой с интерактивным ползунком цветовой температуры, блок «Нам доверяют», рекомендуемые.
- Каталог, категории с сериями, карточка товара: полное описание, все характеристики, галерея, чертежи с увеличением по клику, ориентировочная цена.
- Корзина-заявка (localStorage): добавление из каталога и из карточки, живой счётчик, согласие 152-ФЗ.
- Админка: список заявок (окно с деталями, статус выпадающим списком), CRUD товаров с загрузкой фото/чертежей, динамические характеристики, инлайн-сортировка.
- Контакты и реквизиты ООО «ЗАРЯД», страница политики ПДн (шаблон — заменить полным текстом).

## Структура
```
app.py                 модели, роуты, init_db() (сиды при первом запуске)
seed_data.py           реальные данные каталога LampTek
requirements.txt
scripts/fetch_assets.py    разовое скачивание картинок со старого сайта
instance/lamptek.db        SQLite (создаётся автоматически)
static/css/style.css       дизайн-система, светлая/тёмная тема
static/js/main.js          тема, корзина, ползунок, лайтбокс, форма заявки
static/js/admin.js         окно заявки, статусы, сортировка, форма товара
static/products|drawings|about    локальные изображения (плейсхолдеры → fetch_assets)
static/uploads             загрузки из админки
templates/                 base + страницы + admin/
```

## Перед продакшеном
- **Цены — ориентировочные заглушки**, замените в админке.
- **SMTP:** заполните `SMTP_*` (с SPF/DKIM, иначе письма в спам). Без него заявки пишутся в лог. Можно включить дубль в Telegram (`TELEGRAM_*`).
- **Хостинг в РФ** + перенос на PostgreSQL по желанию: смените `DATABASE_URL` (Flask-SQLAlchemy поддерживает `postgresql://...`, добавьте `psycopg2-binary`).
- Замените `SECRET_KEY`, пароль админа, добавьте полный текст политики 152-ФЗ.
- Запуск под нагрузкой — через `gunicorn app:app` за Nginx (не `python app.py`).
- Логотипы клиентов в блоке «Нам доверяют» — монограммы-заглушки, поставьте реальные.
